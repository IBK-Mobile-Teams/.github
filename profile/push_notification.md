# Push Notification

## Save Push Notification Token
This document provides the technical specifications for saving a user's Firebase push notification token to the server.

### # Overview
The primary purpose of this endpoint is to store the unique push notification token generated by Firebase for a specific user's device. This process is essential for sending targeted push notifications.

This action must be triggered immediately after a user successfully logs in or performs a fast login.

### # Implementation Flow
Here is the required sequence of events on the client side:
- User Authentication: The user successfully completes the login process.
- Get User ID: After login, retrieve the userId of the authenticated user.
- Get Firebase Token: Fetch the latest push notification token from the [Firebase SDK](figma.com/exit?url=https%3A%2F%2Ffirebase.google.com%2Fdocs%2Fcloud-messaging%2Fget-started) on the device.
- API Call: Send the retrieved userId and token to the backend by calling the [API endpoint](https://github.com/IBK-Mobile-Teams/id-gib-server/issues/3) detailed below.

### # API Endpoint
This endpoint saves or updates the user's notification token.

| Header | Description | Required | Example |
| :--- | :--- | :--- | :--- |
| `userId` | The unique identifier for the logged-in user. | Yes | `joditest77` |

### # Request Body
The body should be a raw JSON object containing the notification token.

```json
{
  "token": "c4-co1rWQRa6UVuAqb-T01:...."
}
```

### # Responses
Response
A successful request will return a JSON object indicating the token was saved

```json
{
  "code": "00",
  "message": "Success Save Token",
  "status": "Success"
}
```
